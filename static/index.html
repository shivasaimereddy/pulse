How to read this timeline

Busy periods identify sustained resource usage and the apps observed alongside it. They do not establish the cause of a slowdown. Averages describe the full recorded period, including any part before the selected range.

Storage events are placed at the newer scan time; the change happened somewhere between the two scans. Comparisons of overlapping locations must not be added together. Only retained comparisons are available, and same-size file edits are not detected.

Recording gaps show at least two minutes without saved minute buckets after recording began. Times are approximate. Sleep, downtime, or recording problems can explain a gap; Pulse does not infer its cause. Stopping Pulse stops recording.

How to interpret these observations

These are observed resource patterns, not proof that an app caused a slowdown. CPU and memory periods can overlap. App memory is working-set usage and can include shared pages. Recording starts with this version; earlier hourly history cannot reconstruct these periods.

How process usage is measured

CPU is a share of all logical processors. Group totals reflect matching members; memory sums can include shared pages more than once. Heavy users: ≥1% CPU or ≥256 MB RAM.

Windows and Linux storage

Linux files live inside a virtual disk on Windows. Mounts such as /mnt/c give Linux access to C: — they are already included in Windows usage above. Linux capacity is a virtual limit, not extra physical space.

Before reclaiming WSL space

Review your Linux files through the distribution’s filesystem. Deleting files inside Linux and shrinking its Windows virtual disk are different operations; Pulse does not estimate a reclaimable amount or compact disks automatically.

Docker’s images and volumes can hold valuable data. Use Docker’s own tools to review them before removing anything.

When does Pulse record?

Closing the browser leaves Pulse running. Quitting Pulse stops recording. Pausing live updates only freezes the display; use Save performance history to control recording.
