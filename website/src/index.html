GOOD QUESTIONS

A few things
worth knowing.

Do I need to install anything else?+

No. Download Pulse.exe and double-click it. The portable app includes what it needs to run. Your dashboard opens in your default browser.

Is Pulse a native desktop dashboard?+

Pulse is a local Windows application with a dashboard in your browser. Double-click the executable to start the local service and open your default browser. A small desktop control window lets you reopen the dashboard or quit Pulse.

Does Pulse upload my system data?+

Pulse keeps metrics and scan results on your laptop. The packaged application stores them under %LOCALAPPDATA%\Pulse. No cloud database or account is required.

Will it clean my laptop automatically?+

No. Pulse helps you review storage and resource use, inspect processes, and open relevant Windows tools. It does not automatically delete files, compact WSL disks, or terminate apps. You review and choose the action.

Why does Windows show a publisher warning?+

The current release is not digitally signed. Windows may warn that the publisher is unknown. Only run a copy from a source you trust, and use the SHA-256 checksum to verify it matches the published file.

Does it work with WSL?+

Pulse includes Windows and WSL storage views. Some Linux details require a running distribution, and inaccessible folders may be skipped. Removing Linux files and shrinking a Windows virtual disk are separate operations.
