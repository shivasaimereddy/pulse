Is it an app or a website?+

Pulse is a portable Windows app. Double-click Pulse.exe to start its local service and open the dashboard in your default browser. The dashboard connects to your own PC through a loopback address, not a hosted cloud workspace.

What does Pulse record, and when?+

Pulse records resource trends and app usage summaries while the app is running and recording is enabled. Storage scans are saved when you run them. It cannot reconstruct activity from before it was started. Closing the browser does not stop Pulse; quit from the desktop control window to stop recording.

Can Pulse delete files or end apps?+

Pulse does not automatically delete files. You can review file locations in Explorer and open Windows cleanup tools. You can request to end an eligible process after confirmation; protected processes remain guarded. Unsaved work in an app can be lost when it is ended.

Does a storage scan need administrator access?+

Normal scans run with your current Windows permissions. Inaccessible entries are skipped and reported, so scan totals can be incomplete. Folder sizes are logical file sizes and may differ from physical disk usage. They are not an estimate of safe-to-delete space.

Where is my data? Can I change or remove it?+

The packaged app uses a Pulse data folder under your local Windows app data by default. Settings shows the exact database location and lets you choose another database. You can also clear retained history in the app. To uninstall, quit Pulse and delete the executable. If you also want to remove saved data, delete only the Pulse database files at the location shown in Settings after quitting.

Can I use it offline? How do updates work?+

The local monitoring dashboard does not need an internet connection to operate. Downloads and Windows features you open may use the network. Updates are manual: return here for a newer release, quit Pulse, and replace the executable. Keep your data files to retain saved history.

Why might Windows or my browser warn me?+

The current release is unsigned and may not have an established download reputation. A checksum can confirm that your file matches this site’s published download; it does not verify the publisher’s identity or guarantee safety. Review the source and your security software’s guidance before running any downloaded app.

What makes this more than a live monitor?+

Pulse connects live resource readings with recorded history, grouped app usage, saved storage exploration and scan comparisons. Instead of relying on a single moment, you can revisit recorded periods and compare storage snapshots. History requires Pulse to be running; storage comparisons require more than one scan.
