# Pulse product website

A standalone, responsive website for hosting on your own domain. Plain HTML, CSS, JavaScript, and SVG; no Node.js build, database, external fonts, analytics, or third-party scripts.

## Build and preview

From the project root:

```powershell
python scripts/build_website.py
python -m http.server 8787 --bind 127.0.0.1 --directory website/dist
```

Open http://127.0.0.1:8787. Build the desktop release first if `dist/Pulse.exe` and the matching versioned ZIP are missing. The website builder verifies that their executable hashes match and derives the version, size, and checksums from the actual release.

You can also double-click `scripts/Preview Website.cmd` to build and open the local preview. Keep its terminal open while previewing and close it when finished.

## Host on your domain

Upload the **contents** of `website/dist/` to your static host's public directory, or extract `dist/Pulse-website.zip` there. `index.html` should be at the web root. All asset and download URLs are relative, so hosting under a subdirectory also works. Use HTTPS on your domain.

The site includes `downloads/Pulse.exe`, a portable ZIP, SHA-256 checksums, and third-party notices. Confirm your host allows executable downloads and supports their size. Static hosts with a small file-size limit may require GitHub Releases or another download host; update the link strategy in `scripts/build_website.py` when moving downloads externally.

## Update

Edit content in `website/src/`. Product previews are generated by `scripts/generate_product_previews.py` with illustrative sample data; they are interface illustrations, not captured user sessions. Their caption is visible on the page. Edit the generator to keep them aligned with future product changes.

`website/site.config.json` contains the public site URL and download paths. The product page has no public-source links or implementation-stack marketing.

For each release: update `pulse.__version__`, build the Windows release, then rebuild and upload the website. Source changes do not automatically modify the hosted website or executable. No auto-update service is claimed.

## Hosting metadata

The public URL is configured as **https://pulse.infyss.com/**. The builder generates an absolute canonical URL, Open Graph and Twitter metadata, a sitemap, and structured application data in the initial HTML. Social crawlers do not need to execute JavaScript.

The WhatsApp/social card uses `assets/social.png`, exported at 1200 by 630 pixels. The builder publishes a content-hashed copy and references its absolute HTTPS URL in the metadata, so new artwork receives a new URL. Editable artwork is in `assets/social.svg`; update it through `scripts/generate_social_preview.py` and re-export the PNG when redesigning the card. The public page and image must be reachable without authentication after uploading. WhatsApp may cache earlier cards.

## Verification

```powershell
python -m unittest tests.test_website -v
node --check website/src/main.js
```

The design includes responsive layouts, keyboard-operable preview tabs, native FAQ disclosures, reduced-motion support, image dimensions, and fallback links for downloads and checksums. Dark is the default appearance. The header theme button switches to light; an explicit choice is stored locally and restored before styles paint. Blocked browser storage still allows switching within the page. Social previews retain the dark product artwork.

Run `node tests/test_website_theme.js` to check theme defaults, persistence, early restoration, cross-tab updates, and blocked storage. Check desktop and mobile browsers before public launch.

`node tests/test_website_checksum.js` checks generation of Windows verification commands, published hashes, EXE/ZIP selection, clipboard fallback, and modal controls. The compact dialog provides a PowerShell command that prints MATCH or DOES NOT MATCH on the visitor's computer. It does not select, read, upload, or execute a file in the browser. The expected hashes come from the actual bundled downloads.

The hero display uses one restrained perspective layer rather than stacked projections, preserving the angled visual treatment while limiting enlargement. Its floating text card remains flat and uses no backdrop blur. Product typography is increased independently of the illustrative dashboard artwork.
